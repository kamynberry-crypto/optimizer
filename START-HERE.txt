GRIMACETWEAKS — START HERE

1. Upload this entire folder to a GitHub repository.
2. Make sure .github/workflows/build-windows.yml exists in the repository.
3. Open GitHub Actions.
4. Run "Build Windows x64 EXE".
5. Download the Windows x64 artifact.
6. Extract it and run GrimaceTweaks.exe.

This is a C# WPF application. No Python runtime is required.
