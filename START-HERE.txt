GRIMACE OPTIMIZER V5 - GITHUB READY

1. Upload this project to GitHub, preserving:
   .github/workflows/build-windows.yml

2. Open GitHub -> Actions.

3. Select:
   Build Grimace Optimizer (Windows)

4. Click Run workflow -> Run workflow.

5. Wait for the green checkmark.

6. Open the successful run and download:
   GrimaceOptimizer-Windows-x64

- Game selector
- Common game profiles
- Browse any .exe
- Selected game process priority
- Selected game launch/folder tools
